Global Average Pooling: The Information Blender

[B, 512, 7, 7] ➔ [B, 512]

In the normal image baseline policy, the network collapses all 49 spatial vectors into a single vector through Global Average Pooling (GAP):

Averaging across the 49 patches:
$$\mathbf{z}_{\text{pool}} = \frac{1}{49} \sum_{u=1}^7 \sum_{v=1}^7 \mathbf{x}_{(u,v)} \in \mathbb{R}^{512}$$

Why the Model Does It

It produces a single, compact visual observation token $[1, 512]$ that can be easily conditioned on in the Transformer without blowing up attention compute.

Why It Destroys Interpretability

Once blended into $\mathbf{z}_{\text{pool}}$, the features of the mug handle, microwave, and background walls are entangled into the same 512 numbers. You cannot separate which object drove the action command.

Sparse Autoencoder (SAE): Untangling Superposition

ℝ⁵¹² ➔ ℝ⁴⁰⁹⁶ (Top-K=32)

Instead of letting the 49 spatial vectors get blended blindly, we intercept each vector $\mathbf{x} \in \mathbb{R}^{512}$ with a Sparse Autoencoder.

Spatial Grounding: Whole Objects vs. Parts

IoU Overlap Mapping

We take each active SAE feature and measure where it fires across all 49 cells $(u, v) \in \{1..7\} \times \{1..7\}$, generating a spatial activation heatmap. We upsample this heatmap to $224 \times 224$ and calculate its Intersection-over-Union (IoU) with ground-truth simulator bounding boxes.

The Granularity Question: Object-Level vs. Affordance-Level

Whole-Object Representation

The feature aligns with the entire object bounding box (e.g. the entire $150 \times 120$ pixel region of the drawer).

Kept Set: K_latent = { drawer }
Part-Level / Affordance Representation

The feature fires only on the graspable handle ($20 \times 40$ pixels). The policy completely ignores the rest of the drawer!

Kept Set: K_latent = { drawer_handle }

MDT Action Generator & Causal Interventions

Action Chunk: [10, 12]

The action generator predicts a trajectory chunk $\mathbf{a}_t \in \mathbb{R}^{10 \times 12}$ (10 consecutive timesteps of 12-DoF robot motor commands).

REMOVAL TEST
Clamp excluded object features to zero in the SAE:
f[feat_microwave] = 0.0

Reconstruct $\hat{\mathbf{x}}$ and run MDT. If $\Delta a \approx 0$, the excluded object had zero causal impact.

CONSEQUENCE TEST
Clamp task-relevant features (e.g. handle) to zero:
f[feat_handle] = 0.0

Evaluate in simulation. If task success collapses compared to random ablations, $K_{\text{latent}}$ is causally essential.
