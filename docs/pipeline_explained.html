How Every Vector Maps to Another: Input, Latent Spaces & Action

This document explains exactly what the inputs are, where they come from, what the vector shapes look like, how Global Average Pooling (GAP) collapses spatial information into a dense latent space, and how a Sparse Autoencoder (SAE) untangles that representation into interpretable, groundable object and part-level features.

Stage 01

Visual Observation: Camera Image

Tensor: [B, 3, 224, 224]

Where does it come from?

From the robot simulator (RoboCasa or CALVIN). In RoboCasa, these are static external kitchen cameras (left view / right view) or a camera mounted directly on the robot's wrist (in-hand camera).

In Easy Terms:

It is a standard color photograph of the tabletop. 3 channels correspond to Red, Green, and Blue (RGB). The resolution is $224 \times 224$ pixels.

// Example Pixel Representation
Image Shape = [Batch, 3, 224, 224]
Pixel at (Row: 112, Col: 140): [R=0.82, G=0.12, B=0.14]
// Represents a bright red ceramic mug on the kitchen table.
Stage 02

ResNet-18 Backbone & Layer4 Grid

Tensor: [B, 512, 7, 7]

As the image passes through the convolutional blocks of ResNet-18, the spatial resolution is repeatedly halved while the channel depth increases:

Conv1 + Pool
[64, 56, 56]
Layer 1 & 2
[128, 28, 28]
Layer 3
[256, 14, 14]
Layer 4 (Tap)
[512, 7, 7]

What does the 7 × 7 Grid actually mean?

Imagine dividing the entire camera view into a 7 × 7 chessboard of 49 local square patches (224 / 7 = 32 pixels per patch):

  • Each patch contains an exact 512-dimensional vector: $\mathbf{x}_{(u,v)} \in \mathbb{R}^{512}$.
  • Cell $(u=2, v=3)$ looks at the top-left area where the mug handle sits.
  • Cell $(u=5, v=6)$ looks at the bottom-right where the robot gripper enters the scene.
  • Why tap here? This is the last moment in the entire network where spatial geometry is still preserved before pooling destroys it!
Stage 03

Global Average Pooling (GAP): The "Blender"

Mapping: [B, 512, 7, 7] ➔ [B, 512]

In the standard baseline policy, how does the model turn 49 spatial vectors into a single vector for the policy? It uses Global Average Pooling (GAP):

$$\mathbf{z}_{\text{pool}} = \frac{1}{49} \sum_{u=1}^7 \sum_{v=1}^7 \mathbf{x}_{(u,v)} \in \mathbb{R}^{512}$$

What it does (Intuition):

GAP acts like a blender. It takes the vector from the mug, the vector from the wall, the vector from the gripper, and averages all 49 vectors into one smoothie vector $\mathbf{z}_{\text{pool}}$.

Why it causes an Interpretability Problem:

The smoothie vector knows "there is coffee and a cup somewhere", but you can no longer isolate which object caused which action command. The spatial object identity is completely blended!

Stage 04

Sparse Autoencoder (SAE): Untangling Superposition

Mapping: ℝ⁵¹² ➔ ℝ⁴⁰⁹⁶ (Top-K = 32)

The Core Problem: Superposition & Polysemantic Neurons

In a 512-d vector, individual neurons are polysemantic. For example, Neuron #87 might fire for "red ceramic mugs", "wooden cabinet edges", AND "warning stickers". Deep networks do this because they must represent tens of thousands of real-world visual concepts inside only 512 numbers.

// 1. SAE Encoder (Overcomplete Expansion)
Input: x ∈ ℝ⁵¹² (from one spatial cell)
W_enc ∈ ℝ⁴⁰⁹⁶ × ⁵¹² (8x expansion factor)
f = TopK( ReLU( W_enc · (x - b_dec) + b_enc ), K=32 )
// Out of 4096 units, 4064 are strictly 0.0!
// Only 32 features are active (> 0).
// 2. SAE Decoder (Faithful Reconstruction)
Input: Sparse Code f ∈ ℝ⁴⁰⁹⁶
W_dec ∈ ℝ⁵¹² × ⁴⁰⁹⁶
x_hat = W_dec · f + b_dec ∈ ℝ⁵¹²
// Objective: Minimize Reconstruction Error
Loss = ||x - x_hat||²
Example Monosemantic Units in f:
• Feature #142 (Value: 3.84): Fires ONLY on cylindrical curved rims (Mug Rim).
• Feature #418 (Value: 2.15): Fires ONLY on metallic drawer handles (Grasp Affordance).
• Feature #890 (Value: 4.10): Fires ONLY on the black rubber robot gripper pad.
• Feature #0 to #141, #143 to #417... (Value: 0.0): Completely dormant / silent.
Stage 05

Spatial Heatmaps & Bounding Box Grounding

IoU Alignment: Heatmap ⟷ Simulator Boxes

How do we prove whether Feature #142 belongs to the mug or the drawer? We map where it fires across the 49 spatial cells:

1. 7x7 Feature Map
Check firing value of Feature #142 across all 49 cells:
H_142 ∈ ℝ⁷ ˣ ⁷
2. Bilinear Upsample
Interpolate from 7x7 to full camera resolution:
Heatmap ∈ ℝ²²⁴ ˣ ²²⁴
3. Simulator BBox IoU
Intersect with simulator ground-truth boxes:
IoU(Mug) = 0.82 ➔ Match!

Key Research Question: Whole Object vs. Object Parts

In robot manipulation, does the policy care about the whole object or only its functional interaction affordances?

Object-Level (Whole)

The entire bounding box of the cabinet or drawer $[xmin, ymin, xmax, ymax]$ is considered the target.

Part-Level (Affordance)

The features fire exclusively on the handle or contact rim. The robot policy ignores the body of the drawer and attends only to the graspable part!

Stage 06

Action Generator (MDT) & Causal Feature Ablation

Action Chunk: [B, 10, 12]

The action generator is a Multimodal Diffusion Transformer (MDT). It takes the observation tokens and predicts a chunk of 10 future robot actions:

// Action Tensor Dimensions
Predicted Action: a_t ∈ ℝ¹⁰ ˣ ¹²
• Dimension 10: 10 future timesteps into the future (Action Chunking).
• Dimension 12: Robot state commands (3 arm position velocity, 3 orientation velocity, 1 gripper jaw width, 5 base mobility).

How We Perform Causal Interventions:

Removal Condition Test

For any object outside the latent kept set (e.g. the microwave in a drawer task), force its SAE features to 0:

f[feat_microwave] = 0.0

Reconstruct $\hat{\mathbf{x}}$ and run MDT. If the predicted action chunk remains unchanged ($\Delta a \approx 0$), the excluded object had strictly zero causal influence!

Consequence Condition Test

Force the task-relevant object features (e.g. drawer handle) to 0:

f[feat_drawer_handle] = 0.0

Run closed-loop rollout in the simulator. If the task fails, but ablating a random feature of equal magnitude does NOT fail, the latent kept set is causally consequential!
