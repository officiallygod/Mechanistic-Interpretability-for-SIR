Mental Model & Theory

Core Architectural Principles & Insights

Everything discussed regarding why SAEs work, how they learn, resolution tradeoffs, and causal proofs.

01 Superposition

Why do we need the SAE? Why not just ResNet?

ResNet has only 512 dimensions at `layer4`, but the kitchen contains thousands of visual concepts. Because dimensions are limited, ResNet stores concepts in superposition—Neuron #42 fires simultaneously for a microwave handle, a sink reflection, and a blue texture (polysemanticity).

ResNet: Polysemantic (Tangled)
SAE: Monosemantic (1 Feature = 1 Concept)
02 Unsupervised

How does the SAE learn? Does it check if the robot succeeds?

NO. The SAE is trained completely offline with ZERO simulator interaction. It has no idea a robot or kitchen exists! It only solves an unsupervised dictionary puzzle: reconstructing 512-d activation vectors using only 32 non-zero words out of 4,096.

Objective: min ||x - x̂||² subject to Top-32(f). No reward signal!
03 Sparsity Pareto

Why doesn't it learn an identity shortcut, and why K=32?

Because 4,064 of the 4,096 features are strictly clamped to zero on every forward pass, an identity shortcut is mathematically impossible! Setting $K=32$ (~6% of input dimension) hits the frontier: $\ge 95\%$ variance explained while maintaining strict feature isolation.

Too low ($K=2$): Information loss • Too high ($K=512$): Polysemanticity returns.
04 Modality Separation

Where do we input the language goal in the SAE?

NOWHERE. ResNet processes pure camera pixels; CLIP processes text. They only meet downstream inside the MDT action generator. The SAE taps ResNet before language is combined, isolating objective visual perception from task instructions.

Image ➔ ResNet ➔ [SAE Tap] ➔ MDT Cross-Attention 🠔 CLIP Language
05 Compositionality

Are we doomed if features activate on small pixel clusters?

ABSOLUTELY NOT—WE HIT THE JACKPOT! Complex objects are represented compositionally (e.g. Microwave = Door + Handle + Keypad). If a feature fires only on the 20-pixel handle rather than the whole drawer, we prove policies naturally discover functional affordances!

Affordance-level: { drawer_handle } vs. Whole-object: { drawer_body }
06 Implementation Truth

Why 7x7 vs 4x4? Where do the 49 spatial locations come from?

Canonical ImageNet ResNet uses $224 \times 224 \implies 7 \times 7 = 49$ tokens. However, RoboCasa natively stores $128 \times 128 \implies 4 \times 4 = 16$ tokens. We can either upscale frames to $224 \times 224$ for higher spatial precision, or tap the native $4 \times 4$ stream.

224x224: 49 spatial receptive fields • 128x128: 16 spatial receptive fields.
07 Control Baselines

Do we add distractors? How do they prove causality?

RoboCasa kitchen scenes spawn with 15–25 distractor items (sponges, kettles, mugs). Distractors are our negative control: ablating the handle must fail the robot (0% success), while ablating an equally active distractor must leave the robot unaffected (95% success).

Selectivity Proof: Handle ablation collapses policy; Distractor ablation preserves it.
08 ICLR 2027 Finding

How did SIR "mess up" and why does our project exist?

The ICLR 2027 paper proved that SIR suffered from information leakage—the policy claimed to keep only 2 objects, but secretly relied on leaked information from excluded objects via global graph pooling. When leaks were strictly plugged, success collapsed.

Our Mission: Test if an untouched pixel policy forms an honest, leak-free object set.
Formal Scientific Criteria

The Three Verification Conditions

Adopted from the In-Loop Subset Explanations (ILSE) framework to rigorously test our Latent Kept Set.

D-C 1. DISCOVERY

Discovery Condition

The object selection must emerge naturally from the policy's own representations, rather than being supplied by an external simulator oracle or ground-truth bounding box list.

✓ Passes by construction: Trained end-to-end on image pixels without object loss.
R-C 2. REMOVAL

Removal Condition

Excluded objects must have zero causal influence on the generated trajectory chunk. Clamping non-selected object features to zero in the SAE must leave the motor action unchanged.

Requirement: Δa = ||a_original - a_ablated|| ≈ 0
C-C 3. CONSEQUENCE

Consequence Condition

Ablating the latent kept set features must cause task failure, while ablating a matched random set of distractor features must preserve policy completion.

Selectivity: Success(Kept Ablated) ≪ Success(Distractor Ablated)
