Mental Model & Theory

Core Architectural Principles & Insights

Addressing every key question: superposition, offline reconstruction, resolution reality, and causal proof.

01 Superposition

Why do we need the SAE? Why not just ResNet?

ResNet has only 512 dimensions at `layer4`. Real kitchens contain thousands of visual concepts. Because capacity is limited, ResNet stores multiple concepts in the same neuron (Neuron #42 fires for microwave handle + blue reflection + metallic rim). The SAE untangles this into 4,096 clean monosemantic directions.

02 Unsupervised

How does the SAE learn? Does it check if the robot succeeds?

NO. The SAE is trained completely offline with ZERO simulator interaction. It has no idea a robot or kitchen exists! It only solves an unsupervised dictionary puzzle: reconstructing 512-d activation vectors using only 32 non-zero words out of 4,096 ($\min \|\mathbf{x} - \hat{\mathbf{x}}\|^2$).

03 Sparsity Pareto

Why doesn't it learn an identity shortcut, and why K=32?

Because 4,064 of the 4,096 features are strictly clamped to zero on every forward pass, an identity shortcut is mathematically impossible. $K=32$ (~6% capacity) hits the Pareto sweet spot: $\ge 95\%$ variance explained while maintaining strict feature isolation.

04 Separation

Where does the Language Goal enter the SAE?

NOWHERE. ResNet processes pure camera pixels; CLIP processes text. They only meet downstream inside the MDT action generator. The SAE taps ResNet before language is combined, isolating objective visual perception from task bias.

05 Affordances

Are we doomed if features activate on small pixel clusters?

NO—WE HIT THE JACKPOT! Complex objects are represented compositionally (e.g. Microwave = Door + Handle + Keypad). If a feature fires only on the 20-pixel handle rather than the whole drawer, we prove policies naturally discover functional affordances!

06 Code Reality

128x128 vs. 224x224: Where do the spatial locations come from?

In `SIR_Model`, images are natively stored at $128 \times 128 \implies 4 \times 4 = 16$ spatial tokens at `layer4`. In standard ImageNet, $224 \times 224 \implies 7 \times 7 = 49$ tokens. We can tap the native $4 \times 4$ stream or upscale to $224 \times 224$ for higher spatial precision.

07 Controls

Do we add distractors? How do they prove causality?

RoboCasa scenes spawn with 15–25 distractor items (sponges, kettles, mugs). Distractors are our negative control: ablating the handle must fail the robot (0% success), while ablating an equally active distractor must leave the robot unaffected (95% success).

08 Leakage

How did SIR "mess up" and why does our project exist?

The ICLR 2027 paper proved that SIR suffered from information leakage—the policy claimed to keep only 2 objects, but secretly relied on leaked information from excluded objects via global graph pooling. When leaks were strictly plugged, success collapsed.

Verification Criteria

The Three Verification Conditions

Adopted from the In-Loop Subset Explanations (ILSE) framework.

D-C 1. DISCOVERY

Discovery Condition

Selection must emerge naturally from weights rather than external bounding box labels. Passes by construction on raw pixel policy.

R-C 2. REMOVAL

Removal Condition

Excluded objects must have zero causal influence: clamping non-selected features to zero must leave action unchanged ($\Delta a \approx 0$).

C-C 3. CONSEQUENCE

Consequence Condition

Ablating the latent kept set features must collapse task completion, while ablating matched distractor features preserves success.
